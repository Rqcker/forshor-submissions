# `PTPPlan/`: the PhaseTripleProduct planner and its seeds

The PhaseTripleProduct **proofs** are not here: they live in ForShor
(`ForShor/ShorVerification/Implementation/PhaseTripleProduct`, namespace `Shor.PTP`: `Statement.lean`
defines the vocabulary and states the claims, `Proofs/` has the lemmas, `Main.lean` proves them). This
folder imports them and holds only:

- `Plan.lean`: a Lean planner for banded PTP policies over ForShor's `PTPTable` / `PTPPolicy` and a
  proof that every output is valid for every oracle: `plan_check`, `plan_correct`, `plan_correct_w`,
  `plan_correct_tight`, `plan_ladder`, `plan_choose_visit`, `plan_ne_of_unsorted`, `plan_ne_of_foreign`.
  Namespace `TableGeneration.PTPPlan`. It validates the planner's *output*; it says nothing about how good
  the oracle's choices are.
- `PlanSeeds/`: 31 files generated by `scripts/plan_from_site.py`. Each seed reconstructs a site policy as
  `plan tables n oracle` and proves it (`reconstructs`); the `_unsorted`, `_foreignidx` and `_foreigntab`
  variants are negative controls whose reconstruction the kernel decides to be false
  (`reconstruction_fails`), and which `plan_ne_of_unsorted` / `plan_ne_of_foreign` explain.

`scripts/check_ptp_single_source.py` fails if this fork grows PTP definitions of its own again. The policy
checker is `scripts/check_ptp_policy.py`; it writes its generated modules to `../PTPCheck/` (git-ignored).
